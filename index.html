Sources & rules

数据源与识别规则

先用可验证的公开入口，再逐步增加自动化。

推荐接入顺序

  1. 手动导入公开链接（当前已支持）
  2. RSS / Atom：论坛、博客、政府教育公告
  3. GitHub Actions 定时运行抓取脚本，保存 JSON/SQLite
  4. 人工复核后再进入 CRM 或表格

需求识别信号

择校申请学费签证陪读 命中标题或正文关键词时加标签；同时出现“预算 / 入学时间 / 孩子年龄 / 申请材料”等具体信息时提升优先级。

合规边界

仅处理无需登录即可访问、允许程序访问的公开内容；保留原文、来源链接与日期；不抓取非公开个人资料、不自动私信或群发。

Quick start

三步开始使用

  1. 点击“添加公开问题”，粘贴可公开访问的原文和来源链接。
  2. 选择地区、学段和需求标签；系统会按信息明确程度给出 P1–P3 建议。
  3. 在列表中更新跟进状态，导出 CSV 给团队继续处理。

示例数据来自 Reddit 马来西亚公开社区入口，作为演示记录；正式运营前请人工打开链接核验原文与发布日期。
